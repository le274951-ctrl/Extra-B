# Personal Web Portfolio (Static Multipage Website)

This project is my Extra-B assignment for the Mini-Portfolio.  
It extends the single-page portfolio from Lab 01 into a fully structured **multi-page static website**.

The website is built using only **HTML and CSS**, without JavaScript, as required by the assignment.

---

## 🎯 Objectives
- Create a clean, well-organized personal portfolio website.
- Practice information architecture using multiple pages.
- Apply responsive design techniques using flexbox and simple grid layouts.
- Maintain consistent visual style across all pages.
- Follow proper folder structure and SEO basics.
